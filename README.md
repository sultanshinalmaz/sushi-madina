# Sushi Saudi — сайт суши-доставки в Медине

Одностраничный сайт для [@SUSHI_SAUDI](https://t.me/SUSHI_SAUDI): меню с корзиной,
заказ через WhatsApp отдельно для братьев и для сестёр, отзывы, галерея, карта.
Без сборки и фреймворков — открывается двойным кликом по `index.html`.

---

## Что нужно проверить перед публикацией

1. **Стоп-лист.** Меню на сайте — копия меню бота @SaudiSushiBot_bot на день сборки
   (31 позиция). Если что-то убрали или добавили в боте, поправьте `assets/js/data.js`.
2. **Позиции без карточек.** В канале есть фирменные карточки, которых нет
   в присланном меню бота: моти-мороженое (набор 6 шт., 40 SAR), Cold Brew Arabi
   (15 SAR), компот из кураги (7 SAR), Kiwi Ebi Cream, Healthy Rolls из булгура.
   Если они в продаже — скажите, добавлю с их фото.
3. **Время работы.** На сайте намеренно не указано — в канале режим меняется
   (бывают дни только на самовывоз). Если появится постоянный график, добавьте его.

## Структура

```
Суши Саудия/
├── index.html              разметка всех секций
├── assets/
│   ├── css/style.css       все стили
│   ├── js/data.js          ВЕСЬ КОНТЕНТ: меню, цены, отзывы, контакты, зоны
│   ├── js/app.js           логика: заставка, корзина, фильтры, лайтбокс
│   ├── img/                фото (взяты из Telegram-канала)
│   └── fonts/              Playfair Display, Manrope, Caveat (локальные копии)
├── dev-server.js           локальный сервер для показа (на хостинг не нужен)
└── README.md
```

Правится всё из `data.js` — телефоны, цены, тексты отзывов, зоны доставки, вопросы.
HTML и CSS трогать не нужно.

## Как открыть

Двойным кликом по `index.html` — этого достаточно.

Либо локальным сервером (тогда корректно работает карта и кеширование):

```bash
node dev-server.js
```

Откроется на `http://localhost:5182`.

## Что на сайте

**Заставка.** На фоне — кадр из канала (четыре бокса на скатерти, салфетки
в узоре сэйгайха), он медленно наезжает. Поверх золотой круг «энсо» рисуется
кистью, появляется ролл с короной, въезжают палочки, разлетается кунжут,
и по одной проявляются буквы «SUSHI SAUDI» — затем экран расходится, как
раздвижные двери сёдзи. Играет при каждой загрузке страницы, есть
кнопка «Пропустить».

Отдельно проработано поведение на телефоне: базовые стили заставки вшиты прямо
в `<head>`, поэтому она видна с первого кадра, ещё до загрузки CSS. Анимация
стартует только когда страницу реально видно на экране — если ссылку открыли
из мессенджера и свернули браузер, заставка дождётся возвращения, а не «сгорит»
в фоне. Минимум на экране — 3,6 секунды, потолок — 6,5.

**Меню и корзина.** 31 позиция из бота — шесть категорий: сеты и комбо,
горячие, запечённые, большие запечённые, холодные роллы, соусы и напитки.
Названия, составы и цены совпадают с ботом. Кнопка «В корзину»
запускает анимацию полёта, содержимое сохраняется в браузере. При оформлении
сайт сам собирает сообщение со списком и суммой и открывает WhatsApp
(кнопки заказа сделаны ссылками — так их не режет блокировщик всплывающих окон) —
кнопки «Брату» и «Сестре» ведут на разные номера. Внизу корзины есть
«Очистить корзину»: первое нажатие переспрашивает, второе очищает —
чтобы заказ не смахнули случайно.

**Фото блюд открываются крупно.** Клик по картинке в меню разворачивает её
на весь экран — с названием, ценой и составом; соседние блюда листаются
стрелками или клавишами. То же самое работает в галерее.

**Никаких форм и сбора данных.** Ни имени, ни телефона, ни адреса сайт не спрашивает —
всё уходит прямо в переписку WhatsApp.

**Заказ для братьев и для сестёр.** Отдельные карточки с разными номерами,
плюс плавающая кнопка WhatsApp с тем же выбором.

**Telegram-бот.** Кнопка «Открыть бот» ведёт прямо в @SaudiSushiBot_bot.
Адрес лежит в `data.js` → `contacts.bot`.

**Отзывы.** 12 настоящих сообщений клиентов из WhatsApp, опубликованных
в канале. Секция тёмная — так светлые пузырьки читаются как настоящая переписка
и блок не сливается с кремовым меню. Зелёные — от сестёр, белые — от братьев;
подписи анонимные («Брат из Медины», «Сестра»), номеров и имён нет.
Карточки лежат кладкой в три колонки (на телефоне — в одну), лишние скрыты
за кнопкой «Показать все отзывы».

**Галерея.** 10 фото заказов из канала с просмотром по клику.

**Карта.** Точка самовывоза из бота (24.4804721, 39.6231193) на OpenStreetMap —
без ключей и трекеров, рядом ссылка «открыть в Google Maps». В зонах — условия
доставки из бота: от 100 SAR бесплатно, до 100 SAR — 10 SAR.

## Дизайн

Фирменный стиль взят с реального логотипа и карточек канала: золото, кремовый,
глубокий тёмный фон, корона над роллом.

Узоры настоящие, не абстрактные:

- **сэйгайха** — японские «волны морской синевы», золотом по низу первого экрана;
- **асаноха** — «лист конопли», шестиугольная решётка в фоне меню;
- **энсо** — круг, нарисованный одним мазком кисти: рамка фото на первом экране
  и главный элемент заставки;
- **руб-эль-хизб** — восьмиконечная звезда, разделитель секций и знак в бегущей строке.

Шрифты: Playfair Display (заголовки), Manrope (текст), Caveat (рукописные надписи).
Лежат локально — сайт работает без интернета, кроме карты.

## Откуда контент

Меню (названия, составы, цены, условия доставки, точка самовывоза) — из бота
[@SaudiSushiBot_bot](https://t.me/SaudiSushiBot_bot/app). Фотографии блюд —
фирменные карточки из канала [@SUSHI_SAUDI](https://t.me/SUSHI_SAUDI): с каждой
вырезано само блюдо без текстового блока, затем поднята резкость. Отзывы —
настоящие сообщения клиентов оттуда же. Ничего не выдумано.

Исходники Telegram отдаёт максимум в 800 px по большей стороне, поэтому фото
меню — 840×630 после увеличения с нерезким маскированием. Если у владельца есть
оригиналы съёмки, подставьте их вместо `assets/img/menu-*.jpg` — станет ещё чётче.
